函数怎么写？

fn 名称 { 指令 } 定义函数，@名称 调用。支持中文名称、重复调用和函数间调用；函数共用纸带和指针，以纸带传递数据，不支持递归。

转换会把每次调用替换成函数体。原始 P′′ 没有输入指令，含 , 的程序无法转换成纯原始 P′′。

规则怎么写？

当前状态,读入 -> 下一状态,写入,移动

每行一条规则，字段可混用空格、逗号和中文逗号。例如 q0,1 -> q0,1,R 表示在 q0 读到 1 时写回 1，右移一格并留在 q0。L、R、N 分别表示左移、右移、停在原格。读写符号可由多个字符组成，例如 红蓝 或 A01，每个符号占一格。

状态设置
状态名可以用点号，例如 add.scan 或 clean.0.0。停机、接受、拒绝都可留空。

运行约定与参考
连续运行没有累计步数上限，可随时手动暂停。TM 运行时按需扩展纸带。BF 和 P′′ 最多记录 100,000 个非零格，输入与输出最多各记录 65,536 项。修改代码或初始数据会重置运行；自动保存与导出保存的是代码和初始设置。
默认执行到 , 时暂停询问输入，多个数字用逗号分隔、依次读取。队列用完再次询问；选择“结束输入”后写入 0。也可切回预先输入。P′′ 的 , 是本实验的输入扩展，数值必须小于字母表大小。P′′ 仍向左无限，0 号格为右边界。
