# 编程语言实验

这个实验支持 BF、P′′（P double prime）和确定性单纸带图灵机（TM）。使用纯静态 HTML、CSS 和 JavaScript，无第三方运行依赖。

## 本地运行

在本目录执行：

```powershell
node scripts/serve.mjs
```

浏览器打开 <http://127.0.0.1:4186/>。用 `PORT` 环境变量更换端口。首次完整加载后，Service Worker 缓存本实验的页面与模块，可断网重开。浏览器若禁用 Service Worker，仍可在线使用本地服务器。

## 用法与约定

- BF、P′′ 和 TM 各自保留本机草稿。选择示例会替换当前模式的代码和初始设置，可先导出 JSON 备份。
- 支持运行、暂停、单步、重置与调速。按住左键拖动纸带，触屏可横向滑动；按像素连续移动，松手保留当前位置，不吸附整格。拖动时关闭跟随，点“跟随指针”以平滑过渡恢复。键盘聚焦纸带后可用左右键平移。重置保留跟随开关；未跟随时也保留含小数偏移的查看位置。系统开启减少动态效果时，跟随过渡即时完成。
- 默认遇到 `,` 时暂停并询问输入，支持 `3,72,255` 这样的多个十进制数字（中文逗号、空格或换行也可），依次供输入指令读取。队列用完再次询问。点“暂停”保留等待位置，点“结束输入”后才将后续输入设为 0。单步时填写输入只完成当前一条指令。
- BF 使用双向无限、按需分配的纸带，上方可选 8 位（0～255，默认）、16 位（0～65535）或 32 位（0～4294967295）单元。加减在所选范围内回绕，十进制输入和初始纸带都支持完整范围，不按字节截断。`.` 同时记录完整单元数值和低 8 位字节；十进制显示完整值，文本与 HEX 保持字节语义。也可选择“使用预先输入”，保留 UTF-8、十六进制字节和十进制数字三种格式；预设耗尽时读入 0。
- BF 可选“有符号数（允许负数）”：8 位为 −128～127，16 位为 −32768～32767，32 位为 −2147483648～2147483647。负数用补码存储，纸带与当前格显示有符号值；例如 0 减 1 显示 −1，127 加 1 在 8 位模式回绕到 −128。十进制输入、询问框和初始纸带支持负数；文字与 HEX 仍表示原始字节。底层位宽、加减、零值循环判断和文本/HEX 的低 8 位输出规则保持一致，默认仍是无符号数。该设置随草稿与 JSON 保存，旧文件沿用无符号。
- 输出可切换“文本”“HEX”“十进制”。十进制显示每次 `.` 执行时的完整数值快照，跟随单元位宽和有符号设置，例如 32 位可显示 `1000 4294967295`，有符号可显示 `-2147483648 -1`；不再截断为 8 位。切换回文本或 HEX 仍使用原来字节输出，切换不会重置程序，之后修改纸带也不会改变已记录的数字。
- P′′ 使用原始指令 `λ R ( )`，另增加明确标注的 `,` 输入扩展。`λ` 在当前格加一（按字母表大小回绕），然后左移；`R` 右移。当前格非零时执行圆括号内的循环。纸带向左无限，0 号格为右边界；越界报告错误。输入范围为 0 到字母表大小减一，计算结果留在纸带上。
- 初始纸带从左到右填写，用空格或逗号分隔，可以混用，例如 `1, 0 2，1`。BF 和 P′′ 的最后一项位于 0 号格。TM 的第一项位于 0 号格。三种模式的读写头都从 0 出发。P′′ 的字母表大小可设为 2～4294967296。空白默认为 0，TM 可以更改。
- 修改程序或初始数据会重置执行。自动保存与 JSON 导入导出保存代码、语言及初始设置，不保存执行现场。导入前完成字段与数值校验，无效文件不改变当前实验。
- 连续运行按帧执行，支持随时手动暂停。TM 运行时按需分配纸带格，实际可写入的格数取决于浏览器可用内存。BF 和 P′′ 最多记录 100,000 个非零格、65,536 个输入数值和 65,536 次输出。
- 运行速度可直接键盘填写每秒步数，例如 `1234`；按 Enter 或移开焦点生效，不再使用下拉选择。默认勾选“不限速”，输入数字并确认可直接切回指定速度。速度随草稿和 JSON 保存，运行中修改不重置进度；无效值会提示并继续使用原速度。所有速度都以约 8ms 时间片执行，设置很大的正整数时也可暂停；大于 200 步/秒时每约 50ms 刷新数值、纸带与蓝色标记，输入、完成和暂停立即显示。

本机 Chromium 对 `+[]` 简单循环的同条件测量：旧模式约 19,819 步/秒；新快速模式约 31,482,408 步/秒（1053ms 内执行 33,150,976 步，随后手动暂停成功）。这是该设备、该程序的实测，不是所有程序的固定速度。

BF 的非指令字符忽略（因此注释文字内出现指令符号也会执行）；P′′ 只接受原始指令、输入扩展 `,` 和空白。

## 函数与转换为原始代码

勾选“启用函数扩展”，或直接载入函数示例、点“插入函数”。两种语言都用 `fn 名称 { 指令 }` 定义、`@名称` 调用。名称支持字母、汉字、数字和下划线（不能以数字开头），最长 64 个字符。

```text
fn add3 { +++ }
@add3 @add3
```

上例在 BF 中展开为 `++++++`。P′′ 可定义 `fn inc { λR }`，调用三次展开为 `λRλRλR`。

函数定义本身不执行；支持重复、提前和函数间调用。函数共用纸带与指针，以纸带传递数据，没有独立参数或返回值。定义必须放在主程序循环之外；各函数的括号必须独立匹配。单步仍按展开后的原始指令计数，观察窗显示函数调用路径、调用行和函数体中的源位置。其下固定排列完整展开代码，只移动蓝色执行标记；循环回跳、执行完成都不替换代码内容。长代码仅滚动代码框来显示当前位置，不滚动整个页面。

“转换为原始代码”生成仅含原始指令的代码，可复制或替换编辑器；替换会关闭函数扩展，保留位宽、纸带和输入设置。纯原始 P′′ 不含 `,`，使用该输入扩展时会解释无法转换，不会删除输入或修改源代码。

为保证有限展开，不支持直接或间接递归；最多 256 个函数、64 层调用、200,000 条展开指令，额外限制展开工作量，防止空函数的重复调用无限膨胀。函数开关随草稿和 JSON 保存；未开启时保持原有语言解析方式。

## TM 图灵机

点选「TM 图灵机」，在编辑器里每行输入一条规则，格式为 `当前状态,读入 -> 下一状态,写入,移动`。规则字段和初始纸带可混用空格、逗号和中文逗号。`#` 可用作纸带符号，也可在行首或规则写完后开始注释。每格可存一个多字符符号，例如 `A01`、`红蓝` 或 `🔴🔵`。字母表从空白符号、初始纸带和规则中的读写符号自动汇总。移动指令 `L`、`R`、`N` 分别表示左移、右移和停在原格。旧规则里的 `S` 仍可用于停在原格。

```text
q0,1->q0,1,R
q0,0->halt,1,N
```

默认从状态 `q0` 和 0 号格开始。这两条规则会跳过连续的 1，遇到空白就写入 1 并停机。在「设置初始纸带」填入 `1 1 1` 后，运行结果是四个 1。

在「状态设置」可填写初始、停机、接受和拒绝状态的名称，默认分别为 `q0`、`halt`、`accept` 和 `reject`。名称可用点号连接多段，如 `add.scan`。三个终止状态都可留空。只需要普通停机时，可清空接受和拒绝，在规则中跳转到设置的停机状态。只要后续始终有可执行的规则，机器就可以一直运行。若找不到匹配状态和符号的规则，观察窗会显示「无匹配规则」。状态设置随本机草稿和导出的实验保存。每次单步执行一条规则，蓝色标记指向下一条。

「空白符号」可以填 `□`。此时未写入的格读作 `□`，写入 `□` 会清空当前格。用 `q0 □ -> q0 A01 R` 可以在全空的纸带上持续向右写入 `A01`。把规则改为 `q0 □ -> halt A01 N`，同时将停机状态设为 `halt`，即可写一次后原地停机。空白符号随草稿及实验文件保存。

## BF / P′′ / TM 编码互通

在任一种语言里展开「BF / P′′ / TM 编码互通」。给 `0`、`1`、`2` 各填一个不同的符号，例如 `○`、`●`、`◇`，再点「编码当前实验」。复制编码后，在另一个模式或浏览器里填相同的三个符号，粘贴编码并点「解码并载入」。页面会切换到编码里的语言，恢复该语言的源码和初始设置，可继续运行或单步执行。

编码以现有版本 1 实验 JSON 为内容。JSON 按 UTF-8 转成字节，每个字节用六位三进制数字表示，高位在前，不足补零，再用自定义符号替换三个数字。三个符号均为单个 Unicode 码点时直接拼接，多字符符号用空格分隔。解码允许用空白换行排版。
