## 1. 产品目标与交付边界

一个固定HTTPS地址，在手机、iPad和桌面浏览器打开简洁游戏网格；点图标即可进入，返回大厅不丢存档。无需安装APK。首次在线可玩是第一交付；PWA保存到设备/离线与安全激活是第二交付；每天资源候选到已签目录和启动提醒、动态新增是第三交付。三次交付分别验收，不把后续能力提前写成已支持。

| 编号 | 需求 | 验收映射 |
| --- | --- | --- |
| F01 | 八正式游戏，示范单列；手机两列、平板/桌面自适应，卡片仅图标/名称/短状态 | W01/W02 |
| F02 | 顶层不可变游戏URL、合法内部返回、显式返回大厅、直接链接/刷新；离开前保存或提示未保存 | W01/W06 |
| F03 | 启动与前台15分钟节流检查，区分大厅壳、游戏资源、新增游戏、失败和最近成功时间 | W05/W06/W15 |
| F04 | 用户首次主动保存；候选下载完整核验后下次新会话生效；当前会话及Worker固定版本 | W04/W06–W09/W13/W17 |
| F05 | 逐游戏原生格式导入、兼容导出及完整备份；APK/官网/网页之间均由用户主动文件迁移 | W03/W10/W11/W14 |
| F06 | 保存失败明确提示；移除资源不删存档，清空游戏不能影响其它游戏 | W08/W10/W11/W14 |
| F07 | 同游戏多标签写入revision协调，旧writer不覆盖新档，冲突保留双方原档并允许导出 | W14/W17 |
| F08 | 每日北京时间06:00由GitHub Actions冻结默认分支输入变化生成候选；通过兼容/签名/部署门禁后资源可更新，不等待子游戏Release | W05/W07/W12/W15 |
| F09 | 能力不足明确在线模式；iPad浏览器与主屏幕分别记录，录音拒绝不阻断基本玩法 | W03/W13/W14/W16 |

第一交付的更新提醒使用HTTPS部署描述/资源清单和真实输入差异，不轮询GitHub API、不冒称客户端已验签。第二交付的离线验签可先以本地专用测试密钥验证实现；真实用户离线发行须原隔离签名流程接入并通过部署合同，测试身份/数据不能自动变成正式安装。第三交付只接通网页所需最小闭环，不以完成全部八仓独立发行系统为开工前置。

## 3. 验收集与真实设备边界

W01–W17的具体场景/通过条件以设计第9节为真源，不复制成另一份易漂移清单。开发时在报告中将每项拆成可执行case，并给实际计数/输出/浏览器版本与交互截图。当前17项均未运行。

自动化最少覆盖Chromium、Firefox、WebKit，手机390×844/平板820×1180/桌面1440×900，横竖屏、键盘焦点及真实触摸事件；这些视口和WebKit引擎不能替代真实iOS设备。

真实iPad Safari及添加主屏幕环境必须分别记录：八游戏核心流程、第一次SW控制、保存后关闭再开离线、后台冻结与恢复、存储拒绝/回收、壳升级、文件导入导出、音频/录音拒绝。可先发明确标注的技术预览供用户补验；实机结果未完成前不得标“iOS/PWA正式验收通过”。iPhone及macOS Safari同理按实际设备结果记录，不猜测已覆盖。

导出/导入、配额拒绝或剪贴板不可用有可操作退路；不要求桌面专用File System Access API，不要求后台推送或账号。性能上限在W0逐游戏设备矩阵中冻结，包含最大可选参数和取消/暂停交互，不能仅以页面非空为通过。

## 4. 当前不纳入

原生iOS包、账号/云存档、自动读其它origin或APK沙箱、任意第三方游戏、版本回退选择器、所有仓库自动正式Release，均不属于第一交付。既有回退与全仓自动发行继续保留原待办；不以这些目标扩大本轮范围。
