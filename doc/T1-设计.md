# T1 设计：TurboWarp 网页资源

游戏大厅采用现有动态资源来源锁、ZIP 候选和签名目录。来源锁增加两个 id，每个来源指向私有 GitHub 仓库 `main` 已推送的完整提交，目录为 `web-dist`，文件清单与该目录实际文件严格相同。资源制作器按提交重新克隆并逐文件验证，不读取本地游戏目录，也不把其他项目的开发日志加入公开包。

页面为官方 TurboWarp Packager 对现有 SB3 的封装；原积木、舞台和素材留在 HTML 中。网页适配只处理触摸尺寸、输入提示、本地完整状态和损坏存档保护。大厅 WebView 使用各自的 `https://<id>.appassets.androidplatform.net` 隔离域名；存档合同分别为 `<id>-dynamic-v1`，键分别为 `<id>.state.v1`。

复用生产宿主当前资源协议 2、桥协议 1、资源签名公钥、下载及校验流程。此改动仅更新动态资源来源和目录，不更换宿主 APK。发布时以前一公开签名目录的精确 SHA 与序号为前提，避免覆盖其它会话的并发发布。
