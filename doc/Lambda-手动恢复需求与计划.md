# Lambda 手动恢复需求与计划

## 需求

- 每次打开 Lambda 线路实验室时显示新会话，不自动把本地上次存档覆盖到页面。
- 原有本机存档必须保留；用户可点“恢复已保存状态”显式载入，或点“导入存档”选择 JSON 文件。
- 启动渲染不得先把默认页面写回本机存储，从而覆盖仍待恢复的存档。
- 存档格式、稳定存储键、旧版读取能力及其他游戏的存档行为保持不变。

## 验收

- [ ] 保存/自动保存一份非默认状态，重开后显示新会话，旧数据仍在本机。
- [ ] 点击“恢复已保存状态”后，原表达式、归约进度和函数库恢复。
- [ ] 导入原 JSON 存档后，表达式、轨迹和函数库恢复。
- [ ] 桌面及手机宽度下以上操作可用，无页面错误或横向溢出。
- [ ] 动态资源包能被现行大厅发现并更新，原 APK 版本与四个静态游戏资源不变。

## 实施计划
