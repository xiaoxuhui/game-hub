# Lambda 旧存档回退导出审阅

审阅提交 `b3d53f1`：缺少运行前快照时，读取器导出 Lambda 当前来源的原始 localStorage，而不声称找回了卡住前未保存的内容；原文以分段方式从 WebView 读取。Android 34 模拟器测试覆盖回退、非法索引、损坏快照以及跨分段的中文和表情，`OK (1 test)`。

关键限制：原始恢复文件是来源键值的容器，现有 Lambda 的“导入存档”不能直接导入该容器。必须提供明确选择候选存档的恢复路径并验证；不能把原始文件视为已恢复。回退只包含 Lambda 来源的 localStorage，不包含 IndexedDB 或其他来源。超过大小限制、读取超时或服务工作线程劫持时会报告失败并保留原数据。渲染进程极慢退出仍可能导致救援失败，系统保存窗口也需要用户选择文件位置。
