## 发行门槛与可选改进

**发行前判定与发布后事项：** 最终提交重新构建与签名、独立审核、公开仓库、标签及 Release 已完成，见下方发布后核验。用户接受先发行、稍后完成异机可恢复签名备份；这会使机器损坏时后续同证书升级能力面临风险，应尽快补做。四项目导入导出、断网冷启动、旋转和实际游戏存档隔离/保留列为发布后真机验证，**不是已通过**；首版 Release 已披露这些未测范围。发行证书的模拟器覆盖与私有文件标记已通过，但不替代真实游戏存档。公开 Release 的当前版本查询已实测；下载较新版本和系统安装 UI 仍待下一版端到端核验。
