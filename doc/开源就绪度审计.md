## 发行门槛与可选改进

**当前对外发布阻塞项：** 在另一台设备或离线介质安全备份发行签名与可恢复口令；最终提交需重新构建与签名，记录最终 APK SHA-256，再决定公开仓库、创建标签及 Release。用户确认首版沿用此前独立 APK 的顺序，先在线发布、再由用户在真机安装验收。四项目导入导出、断网冷启动、旋转和实际游戏存档隔离/保留因此列为发布后验证，**不是已通过**；首次 Release 必须披露这些未测范围。发行证书的模拟器覆盖与私有文件标记已通过，但不替代真实游戏存档。真实公开 Release 的应用内下载与系统安装 UI 只能在有可访问 Release 时端到端核验，首次发布前以单元/夹具覆盖并如实说明边界。

**可选改进：** 将 Chrome 冒烟自动化并入 CI；控制 Dependabot PR 分组或并发量。首页及四项目的模拟器截图已入库；无需为离线 APK 建立在线演示。

本轮继续补足可执行的设备证据和候选审阅。正式发布前应以当次最终提交重新构建、核对包内摘要和签名，再执行标签及 Release 流程。
