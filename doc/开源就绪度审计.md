## 发行门槛与可选改进

**必须完成后才能对外发布 APK：** 定稿并安全保管发行签名（调试签名不能替代）；补齐 U01–U11、U14–U15 中除已通过的模拟器四入口/返回外的设备项目，尤其是四项目文件导入导出、断网冷启动、旋转、存档隔离和覆盖升级，并在真机复核；核实最终 APK 的 AndroidX/Kotlin 传递依赖及其许可和通知；把 `Unreleased` 内容写入正式版本条目，记录该版本 APK SHA，再创建标签与 Release。上述操作均尚未授权为本轮发布行为。

**可选改进：** 将 Chrome 冒烟自动化并入 CI；控制 Dependabot PR 分组或并发量。首页及四项目的模拟器截图已入库；无需为离线 APK 建立在线演示。

本轮可在本地继续完善文档与测试，不需要发布授权。正式发布时应以当次最终提交重新构建、核对包内摘要和签名，再执行标签及 Release 流程。
