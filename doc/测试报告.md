## 浏览器检查

从独立资源目录在本机启动临时 HTTP 服务，真实 Chrome Headless 以 390px 手机视口加载四个项目首页及图灵机关卡页。五页的 `document.readyState` 均为 `complete`，调试协议未收到 `Runtime.exceptionThrown`。康威、EML、光学、图灵机首页的 `innerWidth` 与 `body.scrollWidth` 均为 390px；图灵机关卡页原有网格固有宽度导致 `body.scrollWidth=3696px`，在浏览器注入合集专用 CSS 后变为 390px，侧栏宽 364px。合集 Android 容器已加入同样的限定 CSS，尚未在 WebView 实测。

上述只证明页面加载和布局测量，不代替人工操作核心玩法、系统文件选择器或 Android 原生桥。浏览器服务使用本机临时文件，未部署网站。
