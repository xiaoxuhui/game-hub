## 浏览器检查

从独立资源目录在本机启动临时 HTTP 服务，真实 Chrome Headless 分别以 390×844 手机视口和 1280×800 桌面视口加载四个项目首页及图灵机关卡页。共 10 次页面加载的 `document.readyState` 均为 `complete`，调试协议未收到 `Runtime.exceptionThrown`。康威“单步”点击后代数在两种尺寸下都从 0 变 1；图灵机“单步”后步数也从 0 变 1；EML 的输入位置、光学游戏关卡按钮及图灵机关卡列表按钮均已点击且未抛出脚本异常，但未据此断言完整玩法通过。手机上四个首页 `innerWidth=body.scrollWidth=390`；图灵机关卡页原有网格固有宽度导致 `body.scrollWidth=3696`，在浏览器注入合集专用 CSS 后 `innerWidth=body.scrollWidth=390`、侧栏宽 364。桌面五页均无超过视口的整体横向溢出。合集 Android 容器已加入同样的限定 CSS，尚未在 WebView 实测。

上述只证明页面加载和布局测量，不代替人工操作核心玩法、系统文件选择器或 Android 原生桥。浏览器服务使用本机临时文件，未部署网站。
