# 原版 APK 存档迁移说明

合集的包名是 `com.xiaoxuhui.gamehub`，与四个原版 APK 不同。Android 不会把原版应用的私有数据自动带入合集。请先保留原版应用和备份文件，确认合集里导入成功后再决定是否删除原版。

| 项目 | 原版可导出的内容 | 合集内的导入入口 | 范围限制 |
|---|---|---|---|
| 康威生命游戏 | 当前世界、“我的图案”、“我的函数”分别导出 JSON | 相应的“导入”“全部导入”“导入函数库” | 三种文件分别处理；导入方式与重名规则以项目界面为准 |
| EML 计算台 | “保存列表”导出 JSON | “导入列表” | 只迁移列表，不承诺其它临时页面状态 |
| 光学游戏 | 当前关卡导出 JSON | “导入” | 仅当前关卡；游戏总进度没有现成的完整导出入口 |
| 图灵机实验台 | “导出项目”JSON；“导出记录”另为运行记录 | “导入项目” | 项目可导入；运行记录及关卡进度没有对应的完整恢复入口 |

操作顺序：在原版 APK 内逐项导出文件；打开合集中的同一项目，使用其导入按钮选择对应文件；检查内容后重启合集复核。不要把不同项目的 JSON 文件互相导入。合集的保存按钮调用系统“创建文档”界面，由用户选择文件位置；取消界面不会写出文件。网页调用原生桥的返回值仅表示保存请求已受理，实际完成或失败由系统操作后的提示确认。

合集四项目使用同一个 WebView origin。本版固定来源的已知存储键互不相同，构建时静态检查键和直接清空调用，但这不等于浏览器层面的强隔离。设备上的跨项目重置、覆盖升级和持久化仍需要实际测试。
