# N30 游戏卡片图标修正：需求与测试用例

## 目标与范围

修正动态游戏大厅卡片使用通用分类图标、与游戏仓库既有专属图标不一致的问题。将可确认的现成 PNG 原样放入大厅 APK，按稳定游戏 ID 映射；保留没有专属图标游戏的现有分类回退，以及四个内置游戏图标。同步让动态游戏详情标题使用相同映射，避免同一游戏在卡片和详情页图标不同。

只修改游戏大厅仓库。不得修改原游戏仓库、游戏资源 ZIP、资源来源/版本锁、签名资源目录或独立游戏 APK；不得临时创作或重绘图标。发行对象仅为新的游戏大厅 APK。

|---|---|---|
| `abelian-sandpile` | `abelian-sandpile/android/icon-source/icon.png` | APK 映射 |
| `lambda-diagram-game` | `lambda-diagram-game/android/icon-source/icon.png` | APK 映射 |
| `mini-scratch` | `mini-scratch/icon-source/icon.png` | APK 映射 |
| `logic-circuit` | `logic-circuit/icon-source/icon.png` | APK 映射 |
| `traffic-planner` | `traffic-planner/icon-source/icon.png` | APK 映射 |
| `memory-demo` | 大厅仓库 `examples/memory-demo/icon.png` | APK 映射 |
| `red-green-puzzle` | 大厅仓库 `examples/red-green-puzzle/icon.png` | APK 映射 |
| `hex-cell-lab`、`langtons-ant`、`turbowarp-neural-network`、`turbowarp-logic-lab` | 审计未发现现成专属图标 | 保持分类图标回退 |
| `conway`、`eml`、`light`、`turing` | 当前 APK 图标与各自原仓库图标 SHA-256 一致 | 保持不变 |

复制图标后记录字节数与 SHA-256，验证 APK 内文件与源文件逐字节一致。
