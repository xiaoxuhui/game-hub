# 100 款动态游戏兼容通道需求与测试用例

状态：规划中；2026-11-01 用户授权开发、推送并发布大厅 APK。

1. 新版大厅可查询、安装、更新最多 100 个动态游戏，原有四个内置游戏与存档、已安装游戏及版本水位不受影响。101 个动态游戏拒绝；资源摘要、签名、来源、安全预算仍生效。

4. 发布签名 APK，保持 applicationId、生产签名、版本号递增；线上验签、文件摘要和更新机制通过，真机由用户发布后验收。分组设计仍为待办，不纳入本轮。

验收：旧目录 16/17、新目录 100/101、签名伪造和资源越权、两通道切换与回退、已安装数据、断网重启、旧目录与新目录更新交错、分页/中断恢复、真实设备或模拟器覆盖升级；自动化命令和证据在实施计划中记录。
