# Lambda 运行前备份原型审阅

审阅对象：`fc2de3a`。结论：**不可发布，仍是隔离原型**。

- 浏览器中 Ω 循环可触发下载请求，但安卓的文件保存桥会打开系统选择窗口；请求不等于文件已写入。必须在安卓 WebView 验证回调、取消、写入成功和失败，不能称为静默自动导出。
- 游戏线程彻底卡死或重进时 C5 同步重放卡死，原型中的页面代码无法执行，因而不能完成用户要求。需要在游戏线程之外读取已提前保存的备份，或先修复启动卡死；v0.5.4 现有资源没有这样的救援入口。
- 原型对每次运行生成独立本机快照，避免覆盖原始数据，但缺少空间治理；空间不足时会阻止运行。应设计可验证写出之后的保留策略，不得悄悄丢弃用户数据，也不能让游戏日常运行因重复备份不可用。
- 启动自动覆盖修复只在构建实验中，未集成正式资源；并发编辑和保存点、长历史、旧存档兼容尚未完成验证。
- 当前测试仅 Chrome：Ω 正常循环发起下载、第二次运行保留第一份快照、模拟配额失败不启动运行；没有真机或 Android WebView 测试。

验证输出：`PASS: automatic export requested; repeat preserves previous backup; quota failure blocks run without deleting data`。
