# T1 需求与测试用例：TurboWarp 两作品接入大厅

- **Status**: PENDING
- **Approved**: 2026-10-26，用户要求复用现有神经网络与逻辑小实验室，只接入现有大厅，不制作独立 APK。
- **Type**: feature

## 需求

1. 大厅动态资源列表新增神经网络实验室、逻辑小实验室，原有条目保留。
2. 每项资源只取对应私有仓库已提交的 `web-dist`，用固定提交、文件清单和摘要锁定；公开包只含网页和随附许可。
3. 宿主沿用既有资源协议 2、桥协议 1、本地存档隔离和签名更新流程，不改现有 APK 或内置基线。
4. 刷新或离线重启仍可加载原 TurboWarp 积木作品并恢复各自存档，存档互不串用。

## 验收用例

| ID | 操作 | 预期 |
| --- | --- | --- |
| T01 | 校验来源锁及两份来源文件清单 | 仓库、完整 SHA、目录、许可、存档合同均有效，原有来源不变 |
| T02 | 从 GitHub 固定 SHA 在干净独立目录制作候选 | 11 项资源均通过来源字节、离线资源和 ZIP 摘要校验；重复构建一致 |
| T03 | 在大厅生产 WebView 安装并打开两项资源 | 页面在隔离 origin 加载，禁止外网，触摸可操作，刷新及重启保留存档 |
| T04 | 签署、发布并匿名下载核验新目录与历史链 | 两项可从已有大厅资源频道安装，其他条目仍可用，目录签名与资产摘要相符 |

原作品自身离线交互测试与截图留在各自源码仓库 `evidence/`，大厅只重复验证宿主边界。
