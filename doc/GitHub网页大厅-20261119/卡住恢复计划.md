# 网页游戏卡住恢复：需求、设计与实施计划

状态：VERIFIED（已完成所列 Chromium 测试；Safari / iPad 及浏览器级死循环仍未验证）。用户希望所有游戏长时间卡住或无法进入时自动重置，并可提前手动重置。重置当前运行，不删除 localStorage、IndexedDB 或导出文件；持久存档保留，尚未保存的运行状态可能丢失。

大厅在游戏栏提供重新开始按钮。游戏注入脚本向同源大厅发送心跳；前台约 30 秒未收到心跳时自动重新载入一次，同一次进入连续异常时停止自动重试并提供人工重试，避免反复重载。页面被隐藏时暂停判定，恢复前台后给予完整等待时间。手动重试可随时使用；退出大厅停止检测。游戏间导航后继续接收同一游戏心跳。

浏览器可能把同源页面与大厅置于同一线程或进程；若死循环连大厅计时器一起阻塞，网页自身无法保证执行重置。浏览器或系统强制关闭页面后重新打开是必要的后备方式；不宣称覆盖所有死循环。若故障来自持久存档，重新载入可能仍复现；不能擅自删除存档。

验收：正常打开、手动重置、超时一次重载、持续失败停止循环、隐藏页面不误重载、返回大厅后不触发、重置前后存档保留，真实浏览器测桌面和手机尺寸；回归现有游戏与存储隔离。发布仅更新网页版，保留已上线资源及独立分支并做好审阅留痕。
