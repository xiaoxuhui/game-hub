# GitHub 网页大厅设计

GitHub Pages 提供静态 HTTPS 页面，不运行本地 Node 服务器。生产资源仍从现有正式签名目录取得并验证，按游戏生成固定路径；必须针对同域不同路径设计存储隔离，尤其是 IndexedDB、worker、游戏内部页面跳转与导入导出。适配代码和资源证明需单独审阅，游戏入口不能继续引用 127.0.0.1 的端口。

复用独立网页工作分支与资源验证流程，保留原网页 PWA 的未完成事项。部署到 GitHub Pages 前验证 28 款真实游戏在 GitHub 项目子路径、浏览器存储隔离和无外网资源条件下的实际行为。静态托管可能无法提供自定义响应头，需按可用机制设计并说明安全边界。
