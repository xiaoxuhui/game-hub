# GitHub 网页大厅需求与测试用例

- 用户可从 GitHub 打开的公开网页使用已接入的所有可用游戏，不依赖本机 Node 服务、桌面快捷方式或 Android APK。
- 游戏目录保留已发布的签名资源来源与版本；28 款游戏的资源和入口完整，GitHub Pages 路径在子目录下也能运行。
- 不同游戏的 localStorage、sessionStorage 和 IndexedDB 必须隔离；不覆盖同一 GitHub Pages 域名下已有站点或本机/手机存档。
- 保留游戏自身的存档、导入导出及回退兼容；实际浏览器检查页面、游戏与存储；不将尚未验证的 PWA/离线能力冒称完成。
- 发布前审阅构建产物、测试结果、来源与 GitHub Pages 配置，发布后从公开 HTTPS 地址验证；不得修改原游戏仓库。
