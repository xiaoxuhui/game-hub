# M5 本地资源恢复切片

## 实现与边界

- 更新详情提供恢复上个版本、恢复内置并固定、解除固定、指定失败编号解除隔离和全局可信恢复。确认文字明确保留存档，不承诺存档回到过去；失败编号重试仍要求当前签名目录、兼容性与网络策略。
- 本地恢复使用同一个 UpdateTaskGate 的 LOCAL 令牌，离线不阻止本地动作；与查询、APK 下载、资源下载共享互斥。后台、进入游戏、外部流程会取消尚未开始的动作；原子事务开始后不声称可撤销已提交选择，仍等待 worker 完成再释放任务位。
- 写入、文件/签名复核、读取描述均在应用工作线程；界面只处理确认与状态。恢复后重新计算可下载资源；明确重试只清除对应编号的本轮尝试记录，不恢复其他失败任务。
- 全局可信恢复沿用双份签名高水位，不重置序号，不删除用户存档。单项损坏不会被全局恢复绕过。
- 先前本地版本真实性批改 `74b7da326864188ad08482770ab93589681be4a3` 的独立复审已闭合，更新原件存于 `m5-local-version-independent-review-20261009.md`。
- 加载失败即时销毁与隔离、跨进程提醒缓存、真实 SAF/联网下载及最终发行仍待后续；不标 M5 VERIFIED。

## 验证计划

- JVM 离线本地令牌、互斥、网络变化、外部流程取消、前后台和旧令牌无法释放新任务。
- 模拟器实际通过协调器恢复生产公钥下的内置选择；StrictMode 检查 UI 无同步写盘，重新创建存储读取固定状态，再解除固定。该用例不代表生产资源 ZIP 的在线下载，也不代替进程终止验证。
