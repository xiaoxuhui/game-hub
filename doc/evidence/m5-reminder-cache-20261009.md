# M5 跨进程更新提醒缓存切片

## 实现和权限边界

- APK 历史提醒以 AtomicFile 保存通过更新策略校验后的版本、资产 ID、大小、摘要与原检查时间。重启在后台恢复；已安装版本相同/更高时不再显示可更新目标。缺失不假称最新，损坏/时间异常显示历史不可用。
- 游戏历史从两份完整签名高水位重建，要求序号/负载与当前可信水位一致。缓存文件仅记录对应序号、摘要和检查时间，匹配失败不挪用旧时间；过期目录只作历史展示，不续期、不生成下载 Offer。
- 卡片标记“上次发现更新，待检查”，大厅提醒标“上次”。旧 APK 目标不提供下载按钮，协调器也拒绝历史目标下载；资源历史不进入可下载集合，只有实际联网查询并重新核验 Release/资产归属、签名/时效后才提供动作。
- 元数据读写、目录签名校验都在应用工作线程；缓存适配器延迟到后台创建，避免首屏触碰文件目录。缓存保存失败不会把已经成功的本次网络查询冒充失败，状态另行标明历史提醒保存失败。
- 初始实际版本仍显示本地核验中，不把历史远端版本填入实际版本；本地 ready/active 的核验显示沿用已有流程。
