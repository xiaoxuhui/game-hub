# M5 加载失败关闭与隔离切片

## 实现

- 主页面或清单登记的必需子资源发生加载错误时，即刻失效导航代次、移除并销毁 WebView、解除 Worker 资源寻址绑定并关闭资源会话。错误面板提供返回大厅和返回资源管理。
- 失败下载身份先以线程安全内存集合禁止重新打开；应用单工作队列随后持久化固定与失败编号隔离。其他游戏会话不受影响；仍持有失败身份自身会话时不提交隔离。应用重启后依据已提交隔离拒绝失败版本，恢复目标同样不能是已隔离版本。
- 修复请求先预约任务位，取消网络任务并等待其清理完成，阻止查询/下载/用户本地事务抢先开始。安全隔离可在后台离线完成；没有把尚未提交的内存禁止标为跨进程隔离已完成。
- 旧 WebView 导航回调被拒绝；旧保存桥捕获导航代次，迟到调用不能打开保存流程。游戏确认对话框在停止或销毁页面时取消。
- 会话引用计数使用 ConcurrentHashMap，关闭会话仅原子减计数，不等待后台完整哈希/证明锁。创建引用仍在存储锁内，安装、激活、恢复、垃圾回收保持原有会话限制。
- 同一已保留安装目录再次安装时，要求完整游戏元数据一致，防止通过重装覆盖已安装版本/来源声明；合法新版需要新资源编号。

## 验证与待验

- JVM：失败身份在提交前禁止打开；有自身会话时拒绝持久化，关闭后允许隔离，其他游戏会话继续；重建存储保留隔离，恢复/解除固定不隐式解除失败编号，只有明确重试可解除。后台证明读取人为阻塞时，关闭会话仍及时完成。
- 任务门禁：等待已有下载清理、连续两项修复、禁止新任务抢占、后台离线执行、旧令牌不释放新任务；查询结束后修复才开始。
- 模拟器：实际内置光学游戏写入星级存档，注入加载错误后确认页面/会话关闭、旧保存桥返回 false，回到大厅再打开仍有真实存档。
- 以上原生错误注入使用内置版本；下载资源持久隔离由 JVM 签名完整 ZIP 夹具证明，不等同于生产密钥下在线下载安装失败的端到端测试。真实进程终止、生产联网、SAF、跨进程通知和最终发行仍待后续；M5 保持 PENDING。
