# M5 实际资源版本与候选时效切片

## 范围与约束

- `GameResourceStore.describeAll` 在工作线程逐文件核对 active/ready 后返回本地状态。区分内置、已下载、完整候选、损坏指针及全局状态错误；损坏 active 不假称已经恢复内置。
- 卡片显示实际版本/来源、待生效、固定版本或远端可更新标记。详情明确区分实际、候选、远端编号；不兼容资源提示所需大厅编号及合同，不能当作可安装版本。
- 已激活资源的签名证明过期仍可离线识别和使用；未激活候选过期显示暂不生效。没有把远端版本名称填进实际版本标签。
- 元数据刷新、安装完成和回到大厅重新读取本地描述；文件核验和签名处理不在 UI 线程。
- 查询接受新的完整签名目录后，`refreshReadyProof` 可续期同身份 ready 的证明：必须是当前已接受序号/负载，完整文件/入口/合同不变、兼容当前大厅且未被隔离，空间满足预算，AtomicFile 写入。保留 active 指针，不下载 ZIP、不静默激活；某候选失败保留现状并记录本地诊断，不阻断其他游戏。
- 本切片新增本地诊断文本展示；恢复、失败会话关闭隔离、通知跨进程缓存与真实在线下载验收仍待后续，M4/M5 继续 PENDING。
