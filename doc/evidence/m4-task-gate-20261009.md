# M4 下载协调策略切片（2026-10-09）

## 行为

UpdateTaskGate 是应用范围协调器的纯状态机基础：冷进程首次检查、30分钟自动重查、手动检查合并；元数据检查与 APK/资源下载互斥；不自动下载APK；非计费Wi-Fi默认自动资源、移动网络须用户设置或本次手动确认。

进入游戏、后台、断网或网络不符合任务确认时取消任务，但保留占用到工作线程清理并finish(token)，避免第二任务撞上仍未结束的连接/解压。过期token的finish不能释放新token。自动设置关闭可以取消自动任务，不撤销已经明确确认的手动任务。两通道退避独立，构造必须显式提供持久化适配器，手动资源下载不能绕过退避；写入适配器失败时先保留内存退避。Android真实持久化将在应用协调器接入时验证。
