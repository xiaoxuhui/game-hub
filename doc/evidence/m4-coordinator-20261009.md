# M4 应用范围协调器首切片

## 范围

- 新增进程单例 `UpdateCoordinator`，只保存 application context；查询、下载、资源安装共用单工作线程及 `UpdateTaskGate`。
- APK 和资源通道独立查询、状态及持久退避。采用匿名固定仓库 HTTP，APK 下载也接入已验证的 HTTP 适配器，获得总时限、实际字节预算、限流及取消检查。
- 使用 Android 网络状态监听：只有经系统验证的在线网络可请求，自动资源下载默认只允许非计费 Wi-Fi；正常权限 `ACCESS_NETWORK_STATE` 同步加入清单及 CI 精确白名单，不增加运行时授权弹窗。
- 资源目录须先验签并交由存储接受防回滚记录。每次成功查询重建本轮候选；同一游戏同一身份在本轮仅自动尝试一次，取消不重新尝试。手动重试仍可显式执行。
- Activity 订阅回调在主线程交付，执行前重新确认订阅仍有效；旋转不重建协调器、门禁、网络监听或下载所有者。界面生命周期实际接线留给下一切片。
- 设置通过同步 SharedPreferences commit 写入；退避保存失败保持当前进程限制并报告失败，不宣称已跨进程保存。
- 取消只标记，连接与私有 `.part` 清理后再释放任务占用；占用释放和状态发布在同一状态锁内，避免完成事件覆盖后继任务。下载进度按百分比节流。
