# M5 启动提示与详情首切片

## 实施范围

- MainActivity 首屏完成本地四卡创建后，在 onStart 订阅应用协调器并启动异步检查；游戏加载与元数据查询分开，启动不显示更新弹窗。
- 顶部提示显示两条通道独立状态，点击查看详情。详情记录各自最后成功检查时间、远端资源版本/编号/来源 SHA/说明/体积、进度及取消。
- 默认自动资源下载和计费网络设置可持久修改；手动非 Wi-Fi 下载必须确认当次使用计费网络，不修改自动设置。
- 大厅 APK 只在明确点击后下载，经现有证书/版本/摘要核验后仍需再次点击确认进入系统安装器。安装结束/拒绝/失败清理缓存并清除“已验证待安装”状态，避免失效提示。
- onStop 取消订阅和更新详情对话框；普通退后台停止下载，旋转保留应用门禁与工作线程。onDestroy 释放游戏会话，不额外撤销旋转保留的下载。
- 进入游戏先取消下载，回大厅才允许继续排队。进度变化只更新详情里的进度文本，避免每个百分比重建设置控件和焦点。
- 离线未成功检查显示“未检查：离线”，不显示已是最新；已有成功状态保留此前检查时间。
