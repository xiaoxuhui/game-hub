# 实施计划：大厅正式图标与版本待办

- **Status**: PENDING
- **Approved**: 2026-10-03 用户同意分阶段推进，本版本先更新大厅图标并仅规划现有四游戏，动态扩展先纳入待办。
- **Type**: feature

## 目标与边界

将当前四方块图案更新为独立、可识别的大厅标志。使用仓库原生矢量资源；主图为薄荷色手柄与蓝色入口轮廓，深色背景，按键采用蓝/金色点缀；不含文字、外部品牌或固定数量子游戏的图标拼贴。符合现有大厅色彩，并在小尺寸能辨识。

同时维护[版本待办](版本待办清单.md)：图标先行，四游戏更新遵循已有 v0.3.0 规划，新增游戏动态目录放入后续阶段。本轮不实现下载资源机制或改动四个原仓库，也不发行 APK。图标替换只修改大厅资源和 Manifest 的图标引用，现有游戏卡片与玩法不属于图标改版。

## 图标需求与验收

| 编号 | 要求 | 验收 |
|---|---|---|
| I01 | 标志与“多个游戏统一入口”一致 | 预览可辨识入口轮廓与手柄，无文字或四品牌拼贴 |
| I02 | Android 24–25 保留普通图标 | 通用 mipmap 矢量图标可编译，包含完整背景与前景 |
| I03 | Android 26+ 自适应图标 | 前景/背景分层，圆形与圆角方形裁切不截断主要标志 |
| I04 | Android 33+ 单色主题图标 | 独立 monochrome 层中手柄按键透明镂空；支持主题的 API33+ 实际启动器中验证，若无法执行明确标未验证 |
| I05 | 小尺寸与可复现 | 保存可编辑矢量源、普通/圆形/主题及 48px 预览；实际 Android 编译通过 |
| I06 | 仅落实当前范围 | 无更新机制代码、APK 版本/发行标签改变；源码来源锁定不变，原仓库无写入 |

所有标志放入 108×108 画布中心安全区域，不在自适应前景内绘制背景蒙版。技术依据：[Android 自适应图标规范](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)。
