# P2 提交后独立视角审阅

审阅对象：`4663c29`。审阅方式：以可能丢失数据或影响其他游戏的使用者视角检查变更与测试，不将离线打开等同于进度保存验证。

- 发现：导入旧备份时，备份中不存在、后来新增的同游戏数据库仍会保留旧记录，可能混入恢复后的状态。批改：在有回滚日志和独占锁的前提下清空此类数据库的数据表；保留数据库结构，避免删除数据库请求被其他页面阻塞后延迟执行。补充新增数据库场景测试。
- 已核查：备份校验、存储类型、导入失败回滚、跨游戏隔离以及浏览器在导入中途退出后恢复均有浏览器测试；熄灯矩阵的实际棋盘通过关闭浏览器、断网重开验证。
- 未关闭的发布风险：其他标签页检测和锁仍需端到端并发测试；仅四款无持久化游戏中的一款新增自动保存，其余游戏尚未逐款验证。不得据此发布或标记全游戏存档验证完成。
- 测试范围：Chrome 自动化；iPad Safari、实际设备和存储被浏览器清除等情况未验证。用户应能导出独立备份，不能宣称浏览器存储绝不丢失。
