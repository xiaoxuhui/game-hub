# 本地网页版设计

采用本机只绑定 127.0.0.1 的大厅服务，逐游戏分配稳定的本地端口隔离 localStorage、IndexedDB 与 Service Worker；大厅以独立页面链接或嵌入运行游戏，提供返回入口。发行目录与资源使用大厅现有生产公钥验证，下载完成、清单匹配后再建立本地入口。游戏 ZIP 解包严格限制路径、大小和文件摘要；不修改原仓库、不依赖用户 Android WebView 桥。

桌面快捷方式启动隐藏的本机服务并打开默认浏览器；端口被占用或服务启动失败时明确提示。此本机入口为已发行资源的本地访问，不代表此前暂停的跨平台 PWA 已全部完成，也不连接手机存档。
