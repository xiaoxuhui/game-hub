# Lambda 原始恢复文件导入审阅

审阅提交 `502f4ff`：导入原始 localStorage 容器时只列出经过结构检查的候选项，用户明确选择；取消时保留当前编辑。隔离浏览器通过候选选择和取消测试。超过 256 步的历史暂不作为候选，避免兼容层同步重放造成再次卡住；该限制意味着不能声称所有旧档都能导入。

发现旧版 `lambda-lab-hub-legacy-v4` 键未纳入候选，需要补齐。最多扫描前 128 个存储项，多余项目保留在原文件中，但目前没有明确告知用户；需要提示。候选导入的完整状态、自动保存、备份留存、Android 原生提示窗口和存储空间不足仍需回归验证。实验脚本与正式转换共用实现，不是独立算法证明；还需生产资源字节校验及行为测试。
