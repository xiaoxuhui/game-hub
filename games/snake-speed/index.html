指令与自动运行

每行单独输出一个大写指令，例如 print("W")。每次点击运行都会先自动重置棋盘，无需手动重新开始。每条 WASD 立即输出并移动一格，按「每步间隔」等待后才执行下一行代码；普通循环和函数里也一样，不用添加 sleep。T 开始或继续，R 回到左上角一格并重置得分。程序结束或停止后，小蛇不会自行多走。

撞墙只让游戏结束，Python 会继续执行并显示普通提示；后续方向指令会忽略，直到输出 R 重置。get_state() 可读取头部、身体、果子、得分等状态。也支持 time.sleep()、await asyncio.sleep() 和可选的 await wait()。

Python 功能范围

使用真正的 CPython 解释器，支持 Python 内置函数、函数定义、类、循环、条件、异常，以及 math、random、json、itertools 等标准库。支持在浏览器虚拟文件系统中读写文件；线程、系统进程和本机桌面等功能受浏览器限制。
