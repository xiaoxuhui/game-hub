玩法说明

  1. 从元件库拖动输入或其他元件到画布放置，也可以点击添加。自由搭建的输入按 A、B、C、D、E 等字母顺序命名。
  2. 左键拖动节点，中键或滚轮缩放，空白处右键拖动视角。触屏可直接拖动空白处。元件可以放在画布任意位置。
  3. 点击或拖动右侧输出圆点，接到目标节点左侧的输入圆点。一个输出可以接到多个节点，每个输入只接收一条线。
  4. 右键点击元件或导线即可删除，右键点击输入圆点可断开该端口。也可以先选中，再按 Delete。
  5. 延迟线初始输出 0。每点一次“下一步”，所有延迟线同时采样各自输入，串联时信号每步前进一级。
  6. 在自由搭建中点击“保存为逻辑门”，选择一个输出并命名。这个输出用到的输入会变成新门的端口，可以从元件库再次放到画布。
  7. 点击输入节点的符号位切换正负，点击数字格切换 0 和 1。也可以点击下方十进制数值直接填写。选中右侧样例可恢复预设输入，点击“检测电路”验证本关全部样例。
运算规则

所有端口使用 1 位符号、4 位整数和 4 位小数，范围为 −15.9375 至 +15.9375。左右移的 N 都必须是非负整数。右移丢弃移出的小数位，运算超出范围时会提示溢出。

正负判断对负数、零和正数分别输出 −1、0 和 +1。将该结果接到「改变符号」的 S 端，A 接待处理的数值。
